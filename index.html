3회차 교안 스타일로 통일한 이유

1, 2회차도 별도 페이지지만, 메인 허브에서는 3회차의 구조적 언어를 기준으로 같은 무드로 보이게 맞췄습니다.

같은 카드 언어

세 회차 모두 동일한 카드, 배지, 패널, 메타 칩 구조를 사용해 한 시리즈처럼 보이게 했습니다.

  • 한눈에 세션 구조가 읽힘
  • 메인 허브와 상세 페이지 톤 일치

깊은 배경 + 보라/청록

3회차 대시보드의 깊은 배경, 보라/청록 포인트를 유지해서 전체를 같은 실험실처럼 느끼게 했습니다.

  • 어두운 배경
  • 포인트 컬러 최소화

기어 변속 같은 리듬

보컬로직의 핵심 비유를 UI 모션에 얹어, 화면이 정적 페이지가 아니라 움직이는 교안처럼 보이게 했습니다.

  • hero 풀스크린
  • 오브/링 모션
운영 메모 학생에게는 이 메인 링크 하나만 주면 되고, 4회차는 공개 전까지 커밍순으로 두면 됩니다. 1~3차는 같은 디자인 체계로 통일되어 있어서 회차를 넘겨도 맥락이 끊기지 않습니다.
